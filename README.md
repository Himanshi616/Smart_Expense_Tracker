# Project title
Smart Expense Tracker

# Overview of the project

I made this project to keep track of my daily expenses.
It helps me to add expenses and check how much money I have spent.

# Features

1. Add an expense
2. View all expenses
3. Find total and average expense
4. Check expenses with a budget

# Technology used

Python and Visual Studio Code

# Python Concepts Used

Lists, functions, loops, if-else, variables and input/output.

# How to Run

Open the main folder(Smart Expense Tracker) and then open code.py file in VS Code and run the program.
Choose an option from the menu and enter the required details.

# Instructions for testing

I tested the program by adding different expenses and
checking the total, average and budget.

# Future Improvements

I can add options to delete expenses and save them permanently.
