# Problem Statement

Managing daily expenses can be difficult when there is no proper record of
where the money is being spent. This project provides a simple way to record
and analyse daily expenses using Python.

# Scope

The project can be used to record daily expenses, view expense details,
calculate total and average expenses, and compare expenses with a given budget.

# Target Users

This project is useful for students and individuals who want to keep a simple
record of their daily expenses.

# High-Level Features

1. Add new expenses
2. View recorded expenses
3. Calculate total expenses
4. Calculate average expenses
5. Check the remaining budget
6. Check whether the budget has been exceeded
